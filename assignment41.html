Q41 - Viva Answer - How I Added Breakpoints

/* I took Q25 earlier project and added at least 2 breakpoints */ /* ORIGINAL - Desktop Default (No media query) */ .hero { display:grid; grid-template-columns:1.2fr 0.8fr; } .card-grid { display:grid; grid-template-columns:repeat(3, 1fr); } /* BREAKPOINT 1 - TABLET (Required - First Breakpoint) 1024px */ @media (max-width: 1024px) { .hero { grid-template-columns:1fr; text-align:center; } /* Stack hero */ .card-grid { grid-template-columns:repeat(2, 1fr); } /* 3 → 2 cols */ .hero h1 { font-size:32px; } /* Smaller heading */ } /* BREAKPOINT 2 - MOBILE (Required - Second Breakpoint) 768px */ @media (max-width: 768px) { .navbar { flex-direction:column; } /* Navbar stack */ .card-grid { grid-template-columns:1fr; } /* 2 → 1 col */ .hero h1 { font-size:26px; } .hero { padding:20px 16px; } } /* BREAKPOINT 3 - BONUS - SMALL MOBILE 480px */ @media (max-width: 480px) { .nav-links a { padding:5px 10px; font-size:11px; } .hero h1 { font-size:22px; } } /* Testing: Resize browser, bottom bar shows active breakpoint */ Desktop >1024px = 3 columns, bg #F8F9FA Tablet 768-1024px = 2 columns, bg #F8F9FA Mobile <768px = 1 column, bg #fff8f0 (visual indicator) Small <480px = 1 column compact, bg #fff2ed

Testing Proof: Bottom fixed bar shows live screen width and active breakpoint. Resize window: >1024 Desktop, 768-1024 Tablet, <768 Mobile, <480 Small Mobile. Also background color changes slightly for visual testing. Screenshots taken for submission: 1200px, 768px, 480px.
