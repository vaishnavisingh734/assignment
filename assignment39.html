Q39 - How It Works (Viva Note) - 2 Level Grid Nesting

/* LEVEL 1 - Outer Layout: Header + Sidebar + Main using Named Areas */ .layout { display: grid; grid-template-columns: 240px 1fr; /* Sidebar fixed 240px, Main flexible */ grid-template-rows: 64px 1fr; /* Header 64px, Content rest */ grid-template-areas: "header header" /* Header spans 2 cols */ "sidebar main"; /* Sidebar + Main side by side */ min-height: 100vh; gap: 12px; } .layout-header { grid-area: header; } .layout-sidebar { grid-area: sidebar; } .layout-main { grid-area: main; } /* LEVEL 2 - Inner Product Grid inside Main - Auto Reflow */ .product-grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(220px, 1fr)); /* Auto reflow */ gap: 16px; } /* Responsive - Outer layout changes areas */ @media(max-width:900px){ .layout { grid-template-columns: 1fr; grid-template-areas: "header" "sidebar" "main"; } }

Q39 me 2-level Grid hai: Outer level header+sidebar+main named areas se, inner level main ke andar product grid auto-fit reflow se. Isse real e-commerce layout banta hai - Header top pe, left me filters sidebar, right me products grid jo automatically reflow hota hai. Myntra, Amazon shopping page yahi pattern use karte hain.
