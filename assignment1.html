Q1 - What happens between typing a URL and seeing the page?

Typing a URL triggers a multi-step process: the browser first looks up the domain in its cache, then performs a DNS lookup to find the server's IP address. It then creates a TCP connection and performs a TLS handshake for HTTPS to secure the connection. After that, the browser sends an HTTP GET request to the server. The server responds with the website files (HTML, CSS, JS). The browser parses the HTML to create the DOM tree, applies CSS, executes JavaScript, and finally renders the complete webpage.
