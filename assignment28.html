Problem: Overflow Kya Hai? (Viva Question)

Overflow tab hota hai jab content apne parent box se bada ho jaye aur bahar nikal jaye. Isse horizontal scrollbar aata hai, layout toot jata hai, mobile me page kharab dikhta hai.

4 Common Reasons: 1) Long unbreakable words/URLs, 2) Images with fixed width bigger than container, 3) Fixed width 500px on small screens, 4) No box-sizing: border-box

Fixes Applied (Q28 Solution):
✅ max-width:100% - Never exceed parent
✅ box-sizing:border-box - Padding included in width
✅ overflow-wrap:break-word - Break long words
✅ img {max-width:100%; height:auto;} - Responsive images
✅ white-space:pre-wrap; overflow-x:auto - Code blocks

Complete Fix Code - Copy This For Any Page

/* Q28 - UNIVERSAL OVERFLOW FIX - Add this to every project */ /* Fix 1: All elements include padding in width */ * { box-sizing: border-box; } /* Fix 2: Body never overflow */ body { overflow-x: hidden; } /* Fix 3: All images responsive */ img { max-width: 100%; height: auto; display: block; } /* Fix 4: Long words break */ p, a, div, span { overflow-wrap: break-word; word-wrap: break-word; word-break: break-word; /* For long URLs like github.com/vaishnavisingh734 */ } /* Fix 5: Code blocks scroll, not overflow */ pre, code { white-space: pre-wrap; overflow-x: auto; max-width: 100%; } /* Fix 6: Containers use max-width not fixed width */ .container { width: 100%; max-width: 1000px; /* Not fixed 1000px */ margin: auto; }
