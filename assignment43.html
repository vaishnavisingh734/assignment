Q43 - Viva Answer - Why Both Grid and Flexbox?

/* Q43 - Reference Landing Page using both Grid and Flexbox appropriately */ PAGE LAYOUT - GRID (2D - rows + columns) .page { display: grid; grid-template-areas: "header" "hero" "features" "products" "footer"; } .page-hero { display: grid; grid-template-columns: 1.2fr 0.8fr; } /* 2 cols */ .feature-grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(240px,1fr)); } .product-grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(220px,1fr)); } .page-footer { display: grid; grid-template-columns: repeat(auto-fit, minmax(200px,1fr)); } WHY GRID? Because these control BOTH rows and columns - 2D layout. Page structure needs 2D. COMPONENTS INSIDE - FLEXBOX (1D - row OR column) .page-header { display: flex; justify-content: space-between; align-items: center; } /* Row */ .hero-content { display: flex; flex-direction: column; gap: 14px; } /* Column stack */ .hero-btns { display: flex; gap: 10px; flex-wrap: wrap; } /* Row of buttons */ .hero-stats { display: flex; gap: 20px; } /* Row of stats */ .p-body { display: flex; flex-direction: column; } /* Card content column */ .price-row { display: flex; justify-content: space-between; align-items: center; } /* Row */ .footer-col { display: flex; flex-direction: column; gap: 8px; } /* Column stack */ WHY FLEX? Because these are 1D - either row OR column, need alignment, space-between, centering. REFERENCE RULE: - Use Grid when you need to control layout in 2 dimensions (page, gallery, product grid, footer columns) - Use Flex when you need to align content in 1 dimension (navbar, button group, card content, price row) - This page is reference example - same as Airbnb, Netflix, Amazon landing pages RESULT: Clean, maintainable, no hack - Grid for macro, Flex for micro.
