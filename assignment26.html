2. Visual Box Model - Annotated

Neeche ka box 4 layers me hai - Bahar se andar tak: Margin → Border → Padding → Content

CONTENT - 80% width - Text + Image area - #e3f2fd Blue PADDING 25px - Green #c8e6c9 BORDER 10px solid Orange #ffcc80 MARGIN 20px auto

Vaishnavi Singh - Content Area

This is CONTENT - where text and image sit. Width 80% of parent.

Padding is space between content and border. Border is orange line. Margin is outer space that separates this element from others.

MARGIN - Outermost
margin: 20px auto;
Transparent space outside border. Pushes other elements away. In screenshot, red area. 20px top-bottom, auto left-right for centering. Not included in element size.
BORDER - Edge
border: 10px solid #ff9800;
Line around padding and content. Visible orange. 10px thick. Can be solid, dashed. Included in total size if box-sizing is content-box.
PADDING - Inner Space
padding: 25px;
Space between content and border. Green area. Background color extends here. Content doesn't touch border because of padding. 25px all sides.
CONTENT - Innermost
width: 80%; background: #e3f2fd;
Actual text/image area. Blue area. This is where your content lives. Width/height defines this area only.

3. DevTools Screenshot - How to Take (For Viva)

Teacher ne screenshot annotate karne ko bola hai - Ye steps karo:

  1. Is page ko Chrome me open karo assignment26.html
  2. Neeche wale blue-orange card par Right Click → Inspect
  3. Right side Styles panel me niche scroll karo - Box Model diagram dikhega (content, padding, border, margin ka colored diagram)
  4. Screenshot le lo: Windows + Shift + S
  5. Paint me open karke arrows lagao aur likho: Content, Padding, Border, Margin
  6. Us screenshot ko box-model-screenshot.png naam se save karke project folder me daal do
  7. HTML me add karo: <img src="box-model-screenshot.png" alt="DevTools box model annotation Vaishnavi Singh">

Calculation for Viva:

Total Width = Content Width (80%) + Padding Left 25px + Padding Right 25px + Border Left 10px + Border Right 10px + Margin Left auto + Margin Right auto
Total Height = Content Height (auto based on text) + Padding 25+25 + Border 10+10 + Margin 20+20

If box-sizing: content-box (default) → Width only counts content
If box-sizing: border-box → Width includes content + padding + border (Better for layout)
