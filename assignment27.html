Viva - Explain Border-Radius & Backgrounds

Border-Radius ke 4 tarike:

  • border-radius: 0px; → Sharp corners - Variant 1
  • border-radius: 16px; → Same radius all 4 corners - Variant 2
  • border-radius: 50%; → Circle (if square image) - Variant 2 image
  • border-radius: 24px 4px 24px 4px; → Top-left, Top-right, Bottom-right, Bottom-left alag - Variant 3 (Most creative)
  • border-radius: 12px 0px 12px 0px; → Image pe bhi apply kiya Variant 3 me

Background ke 3 tarike:

  • background-color: #ffffff; / background: #ffffff; → Solid color - Variant 1
  • background: linear-gradient(135deg, #0F2C61, #1a4a9c); → Gradient (2 colors blend) - Variant 2
  • background-image: radial-gradient(...); background-size: 18px 18px; → Pattern / Dots - Variant 3 - Advanced
