Q32 - How Perfect Centering Works (Viva Note)

/* OUTER WRAPPER - Perfect center technique */ .center-wrapper { display: flex; /* 1. Make flex container */ justify-content: center; /* 2. Horizontal center (main axis) */ align-items: center; /* 3. Vertical center (cross axis) */ min-height: 100vh; /* 4. Full viewport height - needed for vertical center */ } /* LOGIN CARD - Inner flex for 2 columns */ .login-card { display: flex; /* Inner flex for left + right columns */ flex-direction: row; /* Side by side */ } @media(max-width:700px){ .login-card { flex-direction: column; } /* Stack on mobile */ }

Why This is Perfect Centering?

Old method: margin:auto only horizontal, vertical ke liye position:absolute; top:50%; transform:translateY(-50%) hack. Flex me sirf 3 properties: display:flex + justify-content:center + align-items:center + min-height:100vh. Horizontal + vertical both centered, no hacks, responsive, works for any size content. This is modern industry standard.
