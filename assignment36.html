Q36 - How Grid Gallery Works (Viva Note)

/* Simple 3-column gallery */ .gallery { display: grid; /* Make grid container */ grid-template-columns: repeat(3, 1fr); /* 3 equal columns - 1fr = 1 fraction */ gap: 15px; /* Gap between rows and columns */ } /* Responsive - Tablet 2 cols, Mobile 1 col */ @media(max-width:900px){ .gallery{ grid-template-columns: repeat(2, 1fr); } } @media(max-width:500px){ .gallery{ grid-template-columns: 1fr; } } /* Advanced - Auto-fit without media queries for columns */ .gallery-auto { display: grid; grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); /* auto-fit = fit as many as possible, minmax(250px, 1fr) = min 250px, max 1fr */ gap: 15px; }

Why Grid Better Than Flex for Gallery?

Flexbox is 1D (row OR column). Grid is 2D (rows AND columns both). Gallery me rows aur columns dono control karne hote hain, isliye Grid best hai. repeat(3, 1fr) se 3 equal columns, gap se clean spacing. auto-fit + minmax se bina media query ke responsive - browser khud decide karta hai kitne columns aayenge. Flex-wrap me equal height mushkil, Grid me auto equal.
