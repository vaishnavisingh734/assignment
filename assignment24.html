What is Design Token? (Viva Question)

Design token ek variable hota hai jo colour, font size, spacing jaise design values ko ek jagah store karta hai. :root me define karo aur poori website me var(--token-name) se use karo.

Benefit: Agar client bole "saare blue colour ko red karo", to sirf --color-primary change karo, poori site update ho jayegi. Real companies me yahi use hota hai.

Badge - var(--fs-xs)

1. Colour Tokens - :root me defined

--color-primary #0F2C61
--color-accent #FF6B35
--color-bg #F8F9FA
--text-primary #212529
--text-secondary #6C757D
--color-success #28A745


CSS me use: background-color: var(--color-primary);

2. Font Size Tokens - Scale System

--fs-xxl 40px - Hero Heading (Poppins)

--fs-lg 24px - Section Heading

--fs-base 16px - Body Text (Default) - Vaishnavi Singh BCA AI content yahan

--fs-sm 14px - Secondary Text / Captions

--fs-xs 12px - Badges, Labels


CSS me use: font-size: var(--fs-lg);

3. Spacing & Radius Tokens

--space-xs: 4px, --space-sm: 8px, --space-md: 16px, --space-lg: 24px

--radius-sm: 4px, --radius-md: 8px, --radius-lg: 12px, --radius-full: 999px

--shadow-sm, --shadow-md - Box shadows

Ye tokens is card me use hue hain: padding: var(--space-lg), border-radius: var(--radius-lg), shadow: var(--shadow-sm)

4. Complete Code - How I Created Tokens

:root {
  /* COLOURS */
  --color-primary: #0F2C61;
  --color-accent: #FF6B35;
  --color-bg: #F8F9FA;
  --color-surface: #FFFFFF;

  /* FONT SIZES */
  --fs-xs: 12px;
  --fs-sm: 14px;
  --fs-base: 16px;  /* Default */
  --fs-lg: 24px;
  --fs-xl: 32px;

  /* FONTS */
  --font-heading: 'Poppins', sans-serif;
  --font-body: 'Inter', sans-serif;

  /* SPACING */
  --space-sm: 8px;
  --space-md: 16px;
  --space-lg: 24px;
}

/* Usage */
h1 { font-size: var(--fs-xl); color: var(--color-primary); }
body { font-size: var(--fs-base); background: var(--color-bg); }
.card { padding: var(--space-lg); border-radius: var(--radius-lg); }

Viva - Why CSS Variables Better Than Hardcoding?

Without Tokens (Wrong Way):

h1 { color: #0F2C61; } .btn { background: #0F2C61; } .header { background: #0F2C61; } /* 10 jagah same code */

With Tokens (Q24 Correct Way):

:root { --color-primary: #0F2C61; } h1 { color: var(--color-primary); } .btn { background: var(--color-primary); } /* Ek jagah change = sab change */
