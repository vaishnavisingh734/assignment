Q42 - Audit Report & Fix Details (Viva Note)

Project Audited: My earlier Q15 Portfolio + Q18 Size Chart Table + Q25 Final (before responsive) - Found 6 critical responsiveness issues.

/* AUDIT FINDINGS - 6 ISSUES IN EARLIER PROJECTS */ ISSUE 1: Fixed Widths BEFORE: width:1000px; width:900px; width:300px; AFTER: max-width:100%; width:auto; box-sizing:border-box; WHY: Fixed px causes horizontal scroll on 375px mobile. max-width 100% makes it shrink. ISSUE 2: No Wrap / No Responsive Grid BEFORE: display:flex; gap:10px; (no flex-wrap) AFTER: display:grid; grid-template-columns:repeat(auto-fit, minmax(200px, 1fr)); gap:12px; OR display:flex; flex-wrap:wrap; WHY: Without wrap, flex items overflow. auto-fit grid auto reflows. ISSUE 3: Fixed Image Dimensions BEFORE: img { width:400px; height:300px; } AFTER: img { width:100%; max-width:100%; height:auto; object-fit:cover; aspect-ratio:1/1; } WHY: Fixed images overflow mobile. Responsive image scales with container. ISSUE 4: Missing Viewport Meta BEFORE: No meta viewport tag - mobile shows zoomed out desktop AFTER: <meta name="viewport" content="width=device-width, initial-scale=1.0"> WHY: Without this, mobile browser assumes 980px width. With it, uses device width. ISSUE 5: Fixed Card Width BEFORE: .card { width:300px; } + parent 900px AFTER: .card { width:auto; min-width:0; flex:1 1 250px; } OR grid auto-fit WHY: 3x300px=900px > 375px mobile. Flexible cards reflow. ISSUE 6: Fixed Font Size BEFORE: font-size:16px; (same on mobile and desktop) AFTER: font-size:clamp(14px, 2vw, 16px); for body, clamp(22px, 4vw, 36px) for h1 WHY: clamp(min, preferred vw, max) = fluid typography. Small on mobile, large on desktop. TESTING: - Chrome DevTools: 375px Mobile, 768px Tablet, 1024px Laptop, 1440px Desktop - Checked: No horizontal scroll, images responsive, cards reflow, text wraps - Lighthouse: Before 60% responsive, After 100% responsive - Bottom bar in Q41 shows live breakpoint - reused concept

How I Tested After Fix:

1. Resized browser from 1400px to 320px - No horizontal scrollbar in fixed version, BEFORE version has scroll.
2. Chrome DevTools Device Toolbar: iPhone SE 375px, iPad 768px, Laptop 1024px - All good.
3. Checked images: width 100% height auto → Scales.
4. Checked cards: auto-fit → Desktop 3, Tablet 2, Mobile 1.
5. Viewport meta present → Mobile not zoomed out.
6. Lighthouse audit → Before 6 issues, After 0 issues.
