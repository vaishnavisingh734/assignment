Q31 - Responsive Menu Bar using Display: Flex

Vaishnavi Singh | 8127780277 | Shahjahanpur | BCA AI 1st Year

This navbar is built with display:flex only. Resize browser window or open in mobile to see responsive flex-wrap hamburger menu. No external framework used.

display: flex
justify-content: space-between
align-items: center
flex-wrap: wrap
flex-direction: row → column (mobile)

How Flex Works in This Navbar (Viva Note)

.navbar { display: flex; /* Makes children flex items in a row */ flex-direction: row; /* Horizontal layout - default */ justify-content: space-between; /* Logo left, menu right - main axis */ align-items: center; /* Vertically center - cross axis */ flex-wrap: wrap; /* Allow wrapping on small screens */ } .menu { display: flex; /* Menu items also flex row */ flex-direction: row; gap: 8px; /* Space between links */ } @media (max-width:800px) { .menu { flex-direction: column; /* Stack vertically on mobile */ width: 100%; display: none; /* Hidden */ } .menu.show { display: flex; } /* Shown on hamburger click */ .hamburger { display: flex; } }

Why Flex Better Than Float?

Old method float:left + clearfix needed. Flex me 1 line display:flex se horizontal, justify-content se left/right alignment, align-items se vertical center. No clearfix, no extra markup. Responsive ke liye flex-wrap:wrap aur flex-direction:column on mobile.

Viva Answer - Explain display:flex Menu

"Ma'am maine navbar ko display:flex se banaya hai. Parent .navbar pe display:flex; justify-content:space-between; align-items:center; flex-wrap:wrap; lagaya hai taaki logo left me aur menu right me rahe aur vertically center ho. Menu ul bhi display:flex hai row me. Mobile pe @media max-width:800px me menu ko flex-direction:column aur display:none kiya, hamburger display:flex dikhaya. JS se sirf classList.toggle('show') se show/hide hota hai. Flex se bina float ke clean responsive menu banta hai."
