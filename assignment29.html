How Position & Z-Index Used in This Hero (Viva Note)

1. Position Types Used:

  • position: relative on .hero → Parent bana taaki absolute children isi ke andar position ho. Aur .hero-content relative taaki z-index kaam kare.
  • position: absolute on circles, overlay, badges → Parent .hero ke top/left/right/bottom se position kiya. Normal flow se bahar nikal gaye.
  • position: fixed on nav → Scroll pe bhi top pe chipka rahta hai. Viewport se relative.

2. Z-Index Layering (Stacking Order):

Layer Stack (Bottom to Top): z-index: 1 → .hero-bg-circle (Decorative background circles - sabse neeche) z-index: 2 → .hero-overlay (Dark overlay over image - circles ke upar) z-index: 3 → .hero-content (Main heading, text, buttons - overlay ke upar) z-index: 4 → .floating-badge (Floating tags - content se bhi upar) z-index: 100 → nav (Fixed navbar - sabse upar, hamesha dikhega)

3. Why Position Needed?

Bina position ke sab elements ek ke neeche ek aate (normal flow). Hero me humein chahiye background image, uske upar dark overlay, uske upar text, uske upar floating badges - sab ek hi jagah stack ho. Ye sirf position absolute + z-index se possible hai.

.hero { position: relative; } /* Reference for absolute */ .hero-bg-circle { position: absolute; top: -100px; right: -100px; z-index: 1; } .hero-overlay { position: absolute; top:0; left:0; width:100%; height:100%; z-index: 2; } .hero-content { position: relative; z-index: 3; /* Above overlay */ } nav { position: fixed; top:0; z-index: 100; /* Highest */ }
