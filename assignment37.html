Q37 - Auto Reflow Logic (Viva Note)

/* Q37 - Responsive product grid that reflows automatically - NO MEDIA QUERY FOR COLUMNS */ .product-grid { display: grid; /* auto-fit = fit as many columns as possible, collapse empty tracks */ /* minmax(260px, 1fr) = each column min 260px, max 1fr (stretch to fill remaining space) */ grid-template-columns: repeat(auto-fit, minmax(260px, 1fr)); gap: 18px; /* Row and column gap */ align-items: stretch; /* Equal height cards */ } /* How it reflows automatically: Screen 1150px: 1150 / 260 = 4.42 = 4 columns (each ~ 274px) Screen 900px: 900 / 260 = 3.46 = 3 columns Screen 600px: 600 / 260 = 2.3 = 2 columns Screen 300px: 1 column No @media needed! Browser does math automatically. */ /* auto-fill vs auto-fit: auto-fill: Creates as many tracks as fit even if empty - leaves empty space auto-fit: Collapses empty tracks - stretches existing cards to fill row - Better for product grid */

Why This Better Than Flex-Wrap Q33?

Q33 me flex:1 1 250px se wrap hota tha but rows me equal height mushkil aur last row stretch alag hota tha. Grid me auto-fit + minmax se perfect rows and columns, equal height auto align-items:stretch se, gap uniform. No media query for column count - browser automatically calculates. Amazon, Flipkart, Myntra product listing Grid auto-fit use karte hain. This is industry standard for responsive product grid that reflows automatically.
