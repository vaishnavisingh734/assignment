1. Universal Selector (*) - Line 9

* { margin:0; padding:0; } - Ye sab elements par apply hota hai. Har browser ka default margin hata deta hai.

2. Element Selector (h1, p, body) - Line 15-28

Ye tag name se select karta hai. Example: body, h1, p - Pure page ke sabhi h1 blue ho gaye.

3. ID Selector (#header, #footer) - Line 31-43

#header { ... } - ID unique hota hai, # se start hota hai. Ek page me ek ID ek hi baar use hoti hai. Upar ka dark header #header se bana hai.

ID = #header | Class = .card | Element = p | Attribute = input[type="text"]

4. Class Selector (.card, .highlight) - Line 46-63

.card { ... } - Dot se start hota hai. Ek class multiple jagah use ho sakti hai. Ye saare white boxes .card class se bane hain.

Ye .highlight class ka example hai

5. Attribute Selector - Line 66-79

input[type="text"] { ... } - Attribute ke value se select karta hai.
