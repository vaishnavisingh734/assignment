Q33 - Flex-Wrap Logic (Viva Note)

.product-listing { display: flex; /* Flex container */ flex-wrap: wrap; /* KEY - Allow items to wrap to next line */ gap: 18px; /* Space between cards - no margin hack */ justify-content: flex-start; align-items: stretch; /* Equal height cards */ } .product-card { flex: 1 1 250px; /* flex-grow:1 flex-shrink:1 flex-basis:250px */ max-width: 320px; /* Max size cap */ min-width: 240px; /* Min size - prevents too small */ } /* Result: Desktop = 4 cards per row, Tablet = 3, Mobile = 1-2, auto wrap, no media query for columns needed */

Why Flex-Wrap Better Than Float or Fixed Width?

Old: float:left; width:25% + clearfix + media queries for each breakpoint. Flex-wrap me: flex:1 1 250px se browser khud calculate karta hai kitne cards ek row me aayenge based on available width. Gap property se clean spacing. No clearfix, no calculation. Amazon/Flipkart product listing yahi use karte hain, Grid se pehle flex-wrap hi standard tha.
