Q34 - Flexbox Used in Navbar + Hero (Viva Note)

/* NAVBAR */ .navbar { display:flex; justify-content:space-between; /* Logo left, links right */ align-items:center; flex-wrap:wrap; } /* HERO - Two columns side by side */ .hero { display:flex; flex-direction:row; /* Left content + Right image */ justify-content:space-between; align-items:center; /* Vertically center */ gap:30px; min-height:85vh; } .hero-content { flex:1 1 50%; display:flex; flex-direction:column; gap:14px; } .hero-image { flex:1 1 45%; display:flex; justify-content:center; align-items:center; } /* Responsive */ @media(max-width:900px){ .hero { flex-direction:column; } /* Stack vertically on mobile */ }

Why Flexbox for Navbar + Hero?

Navbar me space-between se logo aur menu opposite sides pe, align-items:center se vertical center. Hero me flex:1 1 50% se dono columns 50-50 width, gap se spacing. Mobile pe flex-direction:column se stack ho jata hai - content upar, image neeche. No float, no position hack for layout. Pure flex. Floating cards only decoration ke liye position:absolute hain, layout pura flex se.
