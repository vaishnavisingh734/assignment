Q38 - Named Grid Areas Explained (Viva Note)

/* Parent defines visual map */ .dashboard { display: grid; grid-template-columns: 220px 1fr 280px; /* 3 columns: sidebar fixed, main flexible, rightbar fixed */ grid-template-rows: 60px 1fr 40px; /* 3 rows: header fixed, main flexible, footer fixed */ grid-template-areas: /* VISUAL LAYOUT MAP - Easy to read! */ "header header header" /* Row 1: header spans 3 columns */ "sidebar main rightbar" /* Row 2: 3 areas side by side */ "footer footer footer"; /* Row 3: footer spans 3 columns */ gap: 12px; } /* Children assign themselves to named areas */ .dash-header { grid-area: header; } .dash-sidebar { grid-area: sidebar; } .dash-main { grid-area: main; } .dash-rightbar { grid-area: rightbar; } .dash-footer { grid-area: footer; } /* Responsive - Just change the area map! No need to move HTML */ @media(max-width:1000px){ .dashboard { grid-template-columns: 200px 1fr; grid-template-areas: "header header" "sidebar main" "rightbar rightbar" "footer footer"; } } @media(max-width:650px){ .dashboard { grid-template-columns: 1fr; grid-template-areas: "header" "sidebar" "main" "rightbar" "footer"; } }

Why Named Areas Better?

Without named areas, you use grid-column: 1 / 4 and grid-row: 1 / 2 - numbers confusing. With named areas, you write visual ASCII map "header header header" - instantly clear which area spans where.
